# Exercise — Prepare Files and Practise Copilot Chat

## Exercise Overview

ใช้เวลาเตรียมบัญชีและไฟล์ 15 นาที แล้วฝึก Copilot Chat 45 นาที เราจะใช้ prompt ตัวอย่างงานธนาคารและปรับบริบทกับรูปแบบผลลัพธ์ให้ชัดขึ้น

## Prerequisites

- บัญชีองค์กรที่ได้รับสิทธิ์ Microsoft 365 Copilot และเปิด OneDrive, Word และ Excel ได้
- <DownloadLink href="/downloads/day-1-practice-files.zip">Day 1 practice bundle</DownloadLink> ที่แตกไฟล์แล้ว
- <DownloadLink href="/files/day-1/Business%20Idea.docx">Business Idea.docx</DownloadLink> และ <DownloadLink href="/files/day-1/sample_product_revenue.xlsx">sample_product_revenue.xlsx</DownloadLink>

## Scenario 1 — พร้อมเริ่มงานด้วยไฟล์ตัวอย่าง

### Practice 1 — Prepare account and files {#practice-1--prepare-account-and-files--15-นาที}

<PracticeIllustration id="d1-e03-p01" eager />


เตรียมไฟล์ฝึกใน OneDrive ของบัญชีอบรมให้เปิดใช้งานได้

#### Steps

1. เปิด [Microsoft 365](https://www.microsoft365.com/) ด้วยบัญชีองค์กร แล้วเปิด OneDrive จากตัวเลือกแอป
2. สร้างโฟลเดอร์สำหรับงานฝึกตามชื่อด้านล่าง แล้วอัปโหลดไฟล์ Word และ Excel ที่ดาวน์โหลดไว้

   ```text
   MyCopilot
   ```

3. เปิดไฟล์ Word และ Excel ทีละไฟล์เพื่อตรวจว่าเข้าถึงได้ จากนั้นเปิด [Microsoft 365 Copilot Chat](https://m365.cloud.microsoft/chat) ในบัญชีเดียวกัน

#### Checkpoint

เปิด Chat และไฟล์ฝึกทั้งสองไฟล์ได้ด้วยบัญชีอบรม

## Scenario 2 — ปรับ prompt ให้งานและรูปแบบชัดเจน

### Practice 2 — Compare a first prompt with examples {#practice-2--compare-a-first-prompt-with-examples--20-นาที}

<PracticeIllustration id="d1-e03-p02" />


ใช้ตัวอย่างใน prompt เพื่อกำหนดโทนและรูปแบบหัวข้ออีเมลภายใน

#### Steps

1. เริ่มบทสนทนาใหม่ใน Copilot Chat แล้วส่งคำขอแรก เก็บคำตอบไว้ในบันทึกของคุณ

   ```text
   แนะนำหัวข้ออีเมลแบบมืออาชีพสำหรับการประชุมทบทวนงบประมาณของธนาคารกรุงศรี ซึ่งกำหนดจัดขึ้นในวันพุธหน้า เวลา 14.00 น.
   ```

2. เริ่มบทสนทนาใหม่อีกครั้ง แล้วส่ง prompt ที่เพิ่มตัวอย่างจากโจทย์ต้นฉบับ

   ```text
   นี่คือตัวอย่างหัวข้ออีเมล 2 รายการสำหรับการประชุมภายในธนาคารกรุงศรี:
   - "แจ้งเตือน: ประชุมทบทวนพอร์ตสินเชื่อวันนี้ เวลา 15.00 น."
   - "อย่าลืม: ประชุมเปิดตัวผลิตภัณฑ์ธนาคารดิจิทัลใหม่พรุ่งนี้ เวลา 10.00 น."

   แนะนำหัวข้ออีเมลแบบมืออาชีพสำหรับการประชุมทบทวนงบประมาณ ซึ่งกำหนดจัดขึ้นในวันพุธหน้า เวลา 14.00 น. โดยให้เนื้อหาเป็นการประกาศระดับองค์กร
   ```

3. เปรียบเทียบคำตอบทั้งสองชุด จดว่าโทน รายละเอียดเวลา และความกระชับเปลี่ยนอย่างไร หากจะนำไปใช้จริง ให้แทนวันพุธหน้าด้วยวันที่แน่นอนก่อนใช้

#### Checkpoint

มีคำตอบสองชุดและข้อสังเกตว่าตัวอย่างใน prompt ส่งผลต่อคำตอบอย่างน้อยหนึ่งจุด

### Practice 3 — Refine and verify a result {#practice-3--refine-and-verify-a-result--25-นาที}

<PracticeIllustration id="d1-e03-p03" />


ปรับคำตอบให้ตรงข้อกำหนดแล้วตรวจเทียบข้อมูลที่ให้

#### Steps

1. ในบทสนทนาชุดที่สอง ส่ง prompt เพื่อปรับผลลัพธ์

   ```text
   ปรับหัวข้ออีเมลให้เหลือ 3 ตัวเลือก ความยาวแต่ละตัวเลือกไม่เกิน 80 ตัวอักษร ระบุการประชุมทบทวนงบประมาณและเวลา 14.00 น. ใช้โทนสุภาพ และจัดคำตอบเป็นตาราง ตัวเลือก | หัวข้ออีเมล | จุดเด่น
   ```

2. ตรวจว่าแต่ละตัวเลือกพูดถึงการประชุมที่กำหนด เวลาไม่เปลี่ยน และไม่มีข้อมูลที่ prompt ไม่ได้ให้ ถ้าพบจุดคลาดเคลื่อน ให้บอก Copilot ว่าต้องแก้จุดใดแล้วตรวจซ้ำ
3. ส่งโจทย์คำนวณจากต้นฉบับเพื่อทดลองขอผลที่ตรวจได้

   ```text
   บริษัทแห่งหนึ่งประมวลผลคำสั่งซื้อด้วยตนเอง ใช้เวลาตรวจสอบคำสั่งซื้อละ 15 นาที พนักงานหนึ่งคนทำได้ 30 คำสั่งซื้อต่อวัน หากลดเวลาต่อคำสั่งซื้อลง 50% และให้เวลาทำงานรวมเท่าเดิม จะทำเพิ่มได้กี่รายการต่อวัน แสดงสมมติฐาน สูตร และผลลัพธ์สั้น ๆ ที่ฉันตรวจด้วยเครื่องคิดเลขได้
   ```

4. ตรวจจำนวนเดิม เวลารวม และจำนวนใหม่ด้วยเครื่องคิดเลข แล้วเก็บคำตอบที่แก้ไขแล้วพร้อมข้อสังเกตหนึ่งข้อ

#### Checkpoint

มีคำตอบที่ผ่านการปรับอย่างน้อยหนึ่งรอบ และระบุสิ่งที่ตรวจเองได้ทั้งในข้อความและโจทย์ตัวเลข

## Checkpoint

อธิบายได้ว่าการเพิ่มบริบท ตัวอย่าง รูปแบบผลลัพธ์ และเกณฑ์ตรวจช่วยให้งานชัดขึ้นอย่างไร

## Expected Output

บันทึกเปรียบเทียบ prompt ก่อน–หลัง และคำตอบฉบับที่ผู้เรียนตรวจแล้วหนึ่งชุด
