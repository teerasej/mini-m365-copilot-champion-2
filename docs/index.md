# Mini Microsoft 365 Copilot Champion — Two-Day Course

แบบฝึกหัดสองวันสำหรับพนักงาน Krungsri เริ่มจากมองขั้นตอนงานให้ชัด ฝึก Microsoft 365 Copilot กับไฟล์ตัวอย่าง และสร้างผู้ช่วยเตรียมแฟ้มสินเชื่อ SME สำหรับให้พนักงานตรวจทาน ทุกกรณีฝึกใช้ข้อมูลสมมติหรือข้อมูลสาธารณะที่ระบุไว้ในแบบฝึกหัด

<CourseHero />

เวลาเรียน **09:00–16:00 วันละ 330 นาที รวม 660 นาที หรือ 11 ชั่วโมง** พัก 10:30–10:45 และ 14:30–14:45 พักกลางวัน 12:00–13:00

## เตรียมตัวก่อนเริ่ม

- ใช้บัญชีองค์กรที่มีสิทธิ์ Microsoft 365 Copilot และแอป Word, Excel, PowerPoint, Outlook และ Teams พร้อม OneDrive สำหรับไฟล์ฝึก
- ตรวจว่าเปิด Researcher, Analyst และ Agent Builder ได้ ถ้าเพิ่ม Skill ใน Agent ไม่ได้ ให้ทำขั้นตอนเดียวกันผ่าน Instructions ตามแบบฝึกหัดท้ายวัน
- ดาวน์โหลด <DownloadLink href="/downloads/all-practice-files.zip">ไฟล์ตัวอย่างทั้งหมด</DownloadLink> แล้วแตก ZIP ก่อนเริ่ม หรือเลือกเฉพาะ <DownloadLink href="/downloads/day-1-practice-files.zip">ไฟล์ Day 1</DownloadLink> และ <DownloadLink href="/downloads/day-2-practice-files.zip">ไฟล์ Day 2</DownloadLink> อัปโหลดเฉพาะไฟล์ที่แบบฝึกหัดระบุ
- เตรียม post-it ปากกา และกระดาษสำหรับกิจกรรมเช้าวันแรก

## เก็บผลงานหลังจบหลักสูตร

เก็บคำตอบที่ปรับ prompt แล้ว เอกสาร Word, Excel workbook, research brief, ผลวิเคราะห์ KPI, Agent และร่าง handoff ที่ผ่านการตรวจทานไว้ในโฟลเดอร์งานฝึกของคุณ เลือกหนึ่งวิธีที่ต้องการนำไปทดลองกับงานประจำ แล้วระบุสิ่งที่ต้องให้คนตรวจอีกครั้งก่อนนำผลไปใช้
